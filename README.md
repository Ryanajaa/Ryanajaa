## Featured projects

### [Real-Time Vehicle Speed Detection at a Campus Crosswalk](https://github.com/Ryanajaa/Comvision_Speed_Detection)

Turns an existing CCTV camera into a speed sensor with YOLOv8n, ByteTrack and a perspective transform.

- About 3 % average speed error against 12 GPS-logged test drives; 6 of 6 overspeed drives flagged
- Runs at 30 FPS, with 6.7× lower CPU cost than the previous version
- [Demo video](https://youtu.be/qVpjDTiQrhc)

### [Vehicle Speed Estimation from Dashcam Video](https://github.com/Ryanajaa/dashcam-speed-estimation)

Predicts a car's speed from dashcam frames alone, using multi-gap optical flow, a ResNet18 and a temporal transformer in PyTorch.

- Test RMSE 3.99 km/h, pre-registered before the test set was used
- 1.45 km/h in a later experiment that reads absolute scale from lane-dash spacing
- Solo project on Comma2k19, trained on an 8 GB laptop GPU
